# Axion web fonts

Axion self-hosts the following Google Fonts used by the public process-systems interface:

- Manrope, weights 400, 600, and 700
- Newsreader, regular and italic weight 400
- DM Mono, weight 400

The font projects are distributed under the SIL Open Font License. Source families are available from [Google Fonts](https://fonts.google.com/).
